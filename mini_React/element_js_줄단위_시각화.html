이 페이지는 element.js를 한 줄씩 멈추며 실행하는 디버거가 아니에요. 같은 줄 구조를 그대로 옮기고 줄마다 기록 코드를 끼운 추적용 복사본을 브라우저에서 진짜 DOM 노드로 실행해 단계를 만들어요. 그래서 단계마다 보이는 값은 손으로 쓴 값이 아니라 그 실행에서 나온 값이에요.

검증: 시나리오마다 추적용 복사본의 결과를 진짜 MiniReactElement(같은 파일을 이 페이지에 붙여 실행)의 결과와 비교해 아래 "검증" 칸에 표시해요. 같지 않으면 빨갛게 표시돼요.

한계: 복사본이므로 진짜 파일이 바뀌면 이 페이지의 추적 코드는 따로 고쳐야 해요(미반영 시 검증 칸이 빨갛게 변해 알려 줘요).

한 문장씩 외우기

  1. createTextElement가 글자를 { type: "TEXT_ELEMENT", props: { nodeValue, children: [] } }로 감싼다.
  2. domToVnode가 nodeType을 보고 3이면 글자 VNode, 1이면 요소 VNode를 만들고 그 밖은 null을 돌려준다.
  3. domToVnode가 자식 노드마다 자기 자신을 다시 불러 트리 모양을 그대로 옮긴다.
  4. isFormattingWhitespace가 줄바꿈 있는 공백뿐인 글자를 참으로 판정해 호출한 쪽이 버리게 한다.
  5. normalizeDom이 서식 공백·script·주석을 진짜 DOM에서 지우고 on* 속성을 뗀다.
