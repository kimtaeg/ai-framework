 DEEP DIVE

개념 더 파고들기

"왜 그렇게 만들었을까"를 12주제로. 클로저 스냅샷, key 정체성, LIS, Hook 순서 설계, 이벤트 루프, 경쟁 상태, Fiber 를 직접 실험.
렌더링 파이프라인
  1. setState() → 값 저장 후 microtask 로 업데이트 예약 (Batching)
  2. render() → 루트 함수 실행, 자식 컴포넌트 펼치기 → 새 Virtual DOM
  3. diff(prev, next) → 최소 변경 목록(patches)
  4. applyPatches() → 바뀐 노드만 실제 DOM 반영
  5. useLayoutEffect → DOM 반영 직후 (그리기 전)
  6. useEffect → 화면을 그린 뒤, 이전 cleanup 후 새 effect 실행
