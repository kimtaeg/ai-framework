      h() 사용법과 규칙
      h(태그, 속성, ...자식) 
      h('div', { class: 'box', id: 'a' },
  '텍스트',
  h('b', null, '굵게'),
)
      • 속성이 없으면 null
      • 이벤트: onClick, onInput, onChange, onSubmit
      • style 은 객체: { color: 'red' }
      • 리스트는 items.map(...) + 각 항목에 key
      • 컴포넌트: h(Child, { label: 'x' })
      규칙
      • function App() 이 루트 컴포넌트입니다.
      • useState 같은 Hook 은 App 안에서만, 조건문 없이 호출하세요. (자식 컴포넌트에서 호출하면 에러)
      • 예외: useContext 는 자식에서도 됩니다.
      • state 는 고치지 말고 새로 만들어서 바꾸세요: setList([...list, x])
      • 무한 반복문(while (true))을 쓰면 페이지가 멈춥니다. 그럴 땐 새로고침하세요.
