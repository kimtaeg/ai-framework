    DOM 변경 비교: patch vs innerHTML

    실제 DOM이 느린 이유 = 바꾸는 노드가 많을수록 다시 계산·그리기가 늘어남

    Patch를 누르면 같은 변경을 patch(바뀐 곳만)와 innerHTML 통째 교체로 각각 적용했을 때 바뀐 노드 수를 비교합니다.
