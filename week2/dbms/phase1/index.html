users 테이블의 B+ 트리 인덱스 (차수 4)

          
저장 형식테이블 하나 = 파일 하나(users.tbl), 한 줄 = 레코드 하나. 쉼표·따옴표가 있으면 "..." 로 감싸고 NULL 은 \N, 줄바꿈은 \n 으로 바꿔 "한 줄 = 한 레코드"를 지킵니다. 그래서 레코드가 시작하는 위치(offset)만 알면 그 줄 하나만 읽을 수 있고, B+ 트리는 id → 위치를 기억합니다. 여기서는 위치가 줄 번호이고, 실제 파일(storage-file.js)에서는 바이트 위치입니다.
