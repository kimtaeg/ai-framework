미니 DBMS 한 장 요약

발표 직전에 훑어보는 핵심 정리. 인쇄하면 A4 한 장에 맞춰집니다.

① SQL 처리 흐름

SQL 문자열
→ tokenize: 키워드·이름·숫자·'문자열'
→ parse (재귀 하강): AST
→ plan: id=? / id 범위 / 전체
→ execute: 파일 읽기·쓰기
→ 결과 + 실행 계획

② 토크나이저 · 파서

  • 토큰마다 행·열 위치 → 에러에 표시
  • '' = 따옴표 하나, -- 주석
  • 규칙 하나 = 함수 하나 (insert, select, condition)
  • BETWEEN → >=, <= 두 조건
  • 입력을 이어 붙이면 SQL 인젝션

③ 파일 저장

  • 테이블 = 파일 users.tbl, 한 줄 = 레코드
  • 쉼표·따옴표 → "…", NULL → \N, 줄바꿈 → \n
  • 위치 = 쓸 때의 파일 크기(바이트)
  • 1MB 씩 모아 쓰기 (100만 건 2초)
  • 여러 행 INSERT 는 검사 먼저 → 원자적

④ B+ 트리

  • id → 파일 위치. 데이터는 리프에만, 리프끼리 연결
  • 넘치면 분할: 리프는 키 복사, 내부는 이동 → 루트가 쪼개지면 높이 +1
  • 높이 ≈ logm(n). 차수 64, 100만 건 → 높이 4
  • 범위 = 첫 리프 찾고 옆으로

⑤ 실행 계획

id = 3index-lookup · 1줄
id BETWEEN …index-range
email = …full-scan · 전부
name=… AND id=3id 로 좁힘
