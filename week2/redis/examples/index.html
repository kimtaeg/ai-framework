🔐 로그인 세션

SET EXEXPIRETAG · INVALIDATE슬라이딩 만료
    이 예제에서 볼 것
    • 로그인하면 SET session:토큰 정보 EX 8. 세션은 요청마다 확인하니 빨라야 하고, 잠깐만 있으면 돼서 레디스에 둡니다.
    • "페이지 이동" 은 EXPIRE 로 8초를 다시 채웁니다(슬라이딩 만료). 쓰는 동안은 안 끊기고, 가만히 두면 끊깁니다.
    • 비밀번호를 바꾸면 INVALIDATE user:7 로 그 사용자 세션만 한꺼번에 지웁니다.
    해보기
    • 로그인 3번 → 하나만 계속 "페이지 이동" → 8초 뒤 나머지만 로그아웃됨

    🚦 요청 횟수 제한

    INCREXPIRE고정 윈도원자성

    이 예제에서 볼 것
    • 같은 IP 의 요청을 10초 창 안에 5번까지만. INCR rate:IP 가 1 이면(창의 첫 요청) EXPIRE 10.
    • INCR 은 원자적이라 동시에 몰려도 정확히 셉니다.
    • 로그인 시도 제한, API 사용량 제한, 인증 문자 재전송 제한이 모두 이 구조입니다.
    해보기
    • 연타 12번 → 6번째부터 429 → 10초 뒤 다시 200

    🔒 분산 락

    SET NX PX소유권 확인TTL교착
    • 상황을 고르고 실행하세요.
    이 예제에서 볼 것
    • 서버 여러 대가 같은 작업(예: 하루 한 번 정산)을 동시에 하면 안 될 때. SET lock:job 내토큰 NX PX 600 — 없을 때만 잡고, 600ms 뒤 저절로 풀림.
    • 풀 때는 값이 내 토큰일 때만 지웁니다.
    • 작업이 TTL 보다 길면 락이 먼저 풀려 두 명이 동시에 들어올 수 있습니다 → TTL 을 넉넉히, 작업 중 연장.
    해보기
    • 세 상황을 차례로 실행 → 망가뜨리기 버튼을 켜고 같은 상황 다시
