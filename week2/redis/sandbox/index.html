    예시 
    redis.exec('SET user:1 김정글 EX 60');\nredis.exec('GET user:1');      // "김정글"\nredis.exec('TTL user:1');      // 60\nredis.command(['INCR', 'visits']); // 1
    코드 안에서 쓸 수 있는 것
    • redis.exec('SET a 1 EX 10') · redis.command(['GET', 'a']) — 명령 실행
    • new HashTable() — 직접 만든 해시 테이블 (set / get / delete / snapshot())
    • new MiniRedis({ onWrite }) — 새 저장소 (AOF 실험용)
    • print(…) · await sleep(ms) · time('이름', () => { … })
