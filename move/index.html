같은 목록을 두 방식으로 동시에 바꿉니다. 왼쪽은 key 로 같은 줄을 찾아 DOM 노드를 옮기고(MOVE), 오른쪽은 key 없이 같은 자리의 글자만 바꿔 씁니다. 각 줄의 입력칸에 아무 글자나 적은 뒤 버튼을 눌러 보세요.

빨간 줄 = 입력칸 글자가 다른 줄의 것이 된 줄 (DOM 노드는 그대로인데 내용만 바뀜). 분홍 번쩍 = 옮겨진 줄, 노랑 번쩍 = 글자가 바뀐 줄.
